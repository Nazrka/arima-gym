# Arima Gym

Фитнес-приложение: тренировки дома, на турниках и в зале. Рабочие веса считаются от твоих максимумов, есть календарь с кольцами выполнения, аналитика, карта нагрузки на мышцы и Арима Кана, которая комментирует тренировки.

![Обложка](assets/cover.png)

## Структура проекта

```
arima-gym/
├── index.html            приложение целиком (HTML, CSS, JS, гифки упражнений, спрайты Каны)
├── manifest.webmanifest  данные для установки на телефон (PWA)
├── icons/                иконки приложения с Каной
├── assets/cover.png      обложка для README и соцсетей
├── easter_egg.mp3        фрагмент трека для пасхалки (2:19–2:37)
└── .nojekyll             отключает Jekyll на GitHub Pages
```

## Как выложить на GitHub Pages

1. Создай репозиторий на GitHub, например `arima-gym`.
2. Загрузи в него все файлы из этой папки (Add file → Upload files).
3. Открой Settings → Pages. В пункте Source выбери ветку `main` и папку `/ (root)`, нажми Save.
4. Через минуту приложение откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/arima-gym/`.
5. На телефоне открой ссылку и выбери «Добавить на главный экран»: приложение установится с иконкой Каны.

## Пасхалка и музыка

- Трек уже лежит в проекте: `easter_egg.mp3` (фрагмент 2:19–2:37, 18 секунд). Приложение само его находит рядом с `index.html`.
- Три нажатия на Кану за 1 секунду запускают звук, розовое свечение и падающие стикеры. Через 18 секунд музыка плавно затихает и оверлей закрывается.
- Если заменить файл на полный трек (длиннее 2:38), приложение само начнёт с 2:19 и остановится на 2:37.
- Свой файл можно выбрать и в приложении: Настройки → Пасхалка → «Выбрать аудиофайл» (хранится только в браузере). Кнопка «Запустить пасхалку (тест)» проверяет всё без трёх нажатий.
- Трек чужой (кавер). Не делай репозиторий публичным вместе с ним или используй выбор файла в настройках, чтобы музыка не лежала в открытом доступе.

## Что внутри

- Главная, Дневник (календарь, аналитика, карта нагрузки, рабочие веса), Питание (калории, белок, вода, вес тела, креатин, протеин, предтрен), Настройки.
- Три режима: дома, турники, зал. У каждого дня несколько вариантов упражнений, которые чередуются.
- Умный таймер отдыха (−15/+15 сек, звук без внешних файлов), XP и ранги от Новичка до Титана, экран «Мои рекорды» с историей роста, выбор акцентного цвета.
- Данные хранятся в браузере (localStorage), резервную копию можно скопировать в Настройках.
