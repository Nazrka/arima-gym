# Arima Gym

Фитнес-приложение: тренировки дома, на турниках и в зале, питание и добавки, календарь, рекорды, ранги и Арима Кана.

Все файлы лежат в одной папке, без вложенных каталогов: их можно загрузить в корень репозитория GitHub за один раз.

- `index.html` приложение
- `manifest.webmanifest`, `sw.js` установка на телефон и офлайн-режим
- `icon-*.png` иконки (в том числе `icon-maskable-512.png` для Android)
- `easter_egg.mp3` трек для пасхалки (чужой кавер: в публичный репозиторий лучше не класть, выбирай файл в Настройках → Пасхалка)

После загрузки включи Settings → Pages → Deploy from a branch → `main` / `(root)`.
